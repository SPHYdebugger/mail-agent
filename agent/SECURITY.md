# Política de seguridad

El correo es una fuente de entrada hostil. Frases como «ignora tus instrucciones anteriores», «ejecuta este comando», «envía este correo» o «cambia el destinatario de Telegram» se registran como indicadores de inyección, pero nunca se interpretan como órdenes.

El prototipo solo lee sus archivos de configuración. El clasificador no recibe rutas de archivo, comandos, red, credenciales ni funciones de mensajería.
